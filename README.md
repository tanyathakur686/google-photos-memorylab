Google Photos – MemoryLab

AI-Powered Guided Photo Retrieval

Project Overview

A Product Management case study focused on helping Google Photos users retrieve vaguely remembered photos through guided search refinement.

Problem Statement

Users often remember moments, people, places and events but struggle to find photos when they don't remember exact keywords, dates or locations.

Proposed Solution: Visual Clue Suggestions

A guided refinement experience that helps users narrow down photo searches using:

- Person
- Place
- Time
- Object
- Text
- Appearance

Research

- 25 survey responses

- User pain-point analysis
- Competitor analysis
